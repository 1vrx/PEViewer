## ImGui PEViewer  

  ## Features:  
  -Get Basic Info from Headers  
  -View Sections  
  -View Imports/Exports  
  -Hex View with Ascii representation  
  -Drag and Drop support  
  -Easy to add features  

  ## Info:  
  - See https://github.com/1vrx/dxd9-imgui for the base I used  
  - Supports x64 & x86
